Homepage: [https://readarr.com/](https://readarr.com/)

Readarr is an automated book and audiobook manager built in the same style as the other Arr applications.

## Usage

Set `readarr_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The Readarr web interface can be found at [http://ansible_nas_host_or_ip:8787](http://ansible_nas_host_or_ip:8787).
