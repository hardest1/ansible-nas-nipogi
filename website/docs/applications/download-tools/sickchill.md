Homepage: [https://sickchill.github.io/](https://sickchill.github.io/)

SickChill is a TV episode manager for automatically downloading, sorting, and keeping track of shows.

## Usage

Set `sickchill_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The SickChill web interface can be found at [http://ansible_nas_host_or_ip:8081](http://ansible_nas_host_or_ip:8081).
