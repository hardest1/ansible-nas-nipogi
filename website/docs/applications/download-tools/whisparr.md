Whisparr is an Arr-style media manager following the same general pattern as Sonarr, Radarr, and Readarr.

## Usage

Set `whisparr_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The Whisparr web interface can be found at [http://ansible_nas_host_or_ip:6969](http://ansible_nas_host_or_ip:6969).
