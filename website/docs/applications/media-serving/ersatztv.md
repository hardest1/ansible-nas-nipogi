---
title: "ErsatzTV"
---

Homepage: [https://ersatztv.org/](https://ersatztv.org/)

ErsatzTV lets you build custom live TV channels from media already stored on your server.

## Usage

Set `ersatztv_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The ErsatzTV web interface can be found at [http://ansible_nas_host_or_ip:8409](http://ansible_nas_host_or_ip:8409).
