Homepage: [https://www.netdata.cloud/](https://www.netdata.cloud/)

Netdata is a real-time performance and health monitoring platform for systems and applications.

## Usage

Set `netdata_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The Netdata web interface can be found at [http://ansible_nas_host_or_ip:19999](http://ansible_nas_host_or_ip:19999).
