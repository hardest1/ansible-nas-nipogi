InfluxDB2 is a time-series database commonly used for metrics, events, and observability data.

## Usage

Set `influxdb2_enabled: true` in your `inventories/<your_inventory>/group_vars/nas.yml` file.

The InfluxDB2 web interface can be found at [http://ansible_nas_host_or_ip:8086](http://ansible_nas_host_or_ip:8086).
